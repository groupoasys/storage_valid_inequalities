# storage_valid_inequalities

This repository contains the data sets and code used in the following research works on valid inequalities for energy storage models:

* *Second-Order Cone Valid Inequalities for Set-Point Tracking with Energy Storage* (preprint: [arXiv:2611.21526](https://arxiv.org/abs/2611.21526)).
* *The Polyhedral Structure of Energy Storage Operations: Convex Hull and Valid Inequalities*.

The material is organized in one folder per case study:

| Folder | Problem | Related paper |
| --- | --- | --- |
| [`Set-point tracking problem`](Set-point%20tracking%20problem/) | Set-point tracking with energy storage | *Second-Order Cone Valid Inequalities for Set-Point Tracking with Energy Storage* |
| [`Battery scheduling problem`](Battery%20scheduling%20problem/) | Battery scheduling (energy arbitrage) | *The Polyhedral Structure of Energy Storage Operations: Convex Hull and Valid Inequalities* |

The README of each folder ([set-point tracking](Set-point%20tracking%20problem/README.md), [battery scheduling](Battery%20scheduling%20problem/README.md)) describes the data, the code, the results, how to cite the work and the license.
