# storage_valid_inequalities

This repository contains the data sets and code used in the research titled *Second-Order Cone Valid Inequalities for Set-Point Tracking with Energy Storage*.

All the material is in the folder [`Set-point tracking problem`](Set-point%20tracking%20problem/). Its [README](Set-point%20tracking%20problem/README.md) describes the data, the code, the results, how to cite this work and the license.
